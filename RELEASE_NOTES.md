# Stochas GGD v1.0.0

Stochas GGD 1.0 is the first full release of the Windows-first CLAP note-effect drum sequencer built around GetGood Drums and Bitwig Studio.

The final release promotes the stabilized RC workflow after native MIDI drag-out was confirmed working in Bitwig, then adds the last host-workflow control, playback polish and a focused codebase audit.

## Drag MIDI and sequencer output control

**Drag MIDI** is confirmed working as the fast handoff from Stochas GGD into the Bitwig timeline.

The top bar now also includes **SEQ ON / SEQ OFF**:

- **SEQ ON** plays the current Stochas pattern normally.
- **SEQ OFF** mutes notes generated by the sequencer so a dragged MIDI clip in Bitwig does not double-trigger the same drum part.
- Incoming Bitwig/live MIDI passthrough remains active while the sequencer is off.
- The sequencer mute state is project-persistent.
- Pattern clearing remains available from the Pattern menu.

## Played-note visual feedback

1.0 adds lightweight feedback driven by notes the engine actually schedules, rather than merely by playhead position.

- played-hit glow
- expanding ripple
- articulation-lane flash
- optional velocity-reactive intensity
- configurable effect strength
- configurable decay time
- Reduce Motion mode

The audio thread writes only compact notifications into a bounded lock-free FIFO. Rendering and animation remain on the UI thread. If the visual queue ever falls behind, visual notifications are dropped rather than affecting MIDI timing.

Muted hits and probability-skipped hits therefore do not produce false playback flashes.

## Expanded Settings

The `...` button now opens a larger organized Settings panel covering:

### Appearance
- Graphite, Midnight, Ember and Contrast themes

### Playback & playhead
- centre-follow for timelines wider than the visible canvas
- smooth playhead interpolation
- playhead forward glow

### Editing & audition
- automatic finer grid at high zoom
- Shift-hover velocity inspection
- articulation-name audition

### Played-note effects
- enable/disable played-hit feedback
- ripple
- lane flash
- velocity-reactive intensity
- effect strength
- effect decay
- Reduce Motion

Editor preferences remain local workstation settings. **SEQ ON / SEQ OFF** is project state rather than an appearance preference.

## Final editing workflow

The 1.0 editor retains the stabilized RC feature set:

- 960 PPQ event timeline
- straight and triplet timing
- cell-centred hit presentation and cell-based Draw targeting
- interpolated paint dragging
- right-click erase including off-grid events
- Shift-click multi-selection
- Shift-drag velocity editing with live value bubbles
- Alt-drag free timing with signed tick feedback
- Alt-double-click quantize to the nearest active subdivision
- selection-aware undo/redo
- chained copy/paste repetition
- Rows / Fill / Mirror / Ramp+ / Ramp- / Dyn- / Thin / Dyn+ transforms
- Ghost / Accent / probability / Humanize / Flam / Double actions
- exact active-kit row layouts
- indexed Grooves and Patterns browser
- semantic `.sggdp` pattern storage
- high-resolution MIDI import
- native MIDI drag-out plus conventional file export fallback

## Built-in GGD maps

1.0 includes semantic mappings for:

- GetGood Drums P V
- GetGood Drums P IV
- GetGood Drums Modern & Massive

Patterns are stored by semantic articulation and resolved through the selected kit map, so switching supported kits does not rewrite the musical pattern.

## Stabilization audit

The final pass deliberately avoided rewriting the proven host-PPQ scheduler. It did fix concrete inherited state hazards found during review:

- linked MIDI-map nodes are explicitly initialized instead of relying on indeterminate pointer/state memory
- engine MIDI mapping validity now starts from a defined state
- the event scheduler clears its previous-block marker cleanly when playback restarts

The event scheduling model, 960 PPQ storage, semantic project persistence and live MIDI passthrough remain compatible with the release-candidate series.

## Installation

The release publishes both:

- `Stochas.GGD.clap`
- `Stochas-GGD-v1.0.0-Windows-x64.zip`

For a normal Windows CLAP installation, copy `Stochas GGD.clap` to:

`C:\Program Files\Common Files\CLAP\`

Then rescan CLAP plug-ins in Bitwig if needed.

## Known boundary

A rare experimental GGD Groove Player source pitch (`85`) remains intentionally unresolved rather than being mapped to an uncertain articulation.
