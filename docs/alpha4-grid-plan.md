# Alpha 4 grid pass

- Default timeline zoom: 125%.
- Standard editing grid: 1/16 at normal working zooms.
- Detail grid: 1/32 becomes available at high zoom (350%+), using the existing cell offset/retrigger timing model so project timing remains compatible with the 1/16 engine.
- Visual hierarchy: bar > beat > 1/16 > 1/32.
- Drum-family group separators are intentionally stronger than articulation-row separators.
